# Admin Sample

简要说明

## 项目简介
`Admin Sample` 是一个基于ABP vNext的通用权限管理框架，包含WPF与Web项目示例。

## 主要特性
- 基于 WPF 的桌面 UI（MVVM 模式）
- 模块化的视图与视图模型组织
- 基于ABP vNext

## 目录结构
- `Admin.Desktop` — WPF 客户端
- `Admin.HttpApi.Host` — Api 接口服务
- `Admin.DbMigrator` — 数据迁移控制台程序
- `Admin.Web` — 基于Layui 的 Web 项目
